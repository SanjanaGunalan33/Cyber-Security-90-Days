## Day 1

## CIA Triad
  1. Confidentiality: Only authorized people should access information. For example if a student logs into an university portal they shouldn't have access to view other students details.
  2. Integrity: Information shouldn't be altered. For example, a student's grades or sensitive information shouldn't be falsely altered.
  3. Availability: The application should be accessible to credible users at all times. For example, if many students are trying to access the university portal and they are not able to access it because of traffic it is an Availability problem.

## Asset
Asset is anything valuable that needs to be protected. Information itself can be an asset
Example: Customer Database, Source code, Passwords, Web Server, Source code etc. 

## Threat
Something that can potentially cause harm to an asset.
Example: Attacker, Malware, Hardware Failure, Malicious employee

## Vulnerability
A weakness that can be exploited.
Example: A weak password, exposed database, Incorrect permissions

## Exploit
The process of using the vulnerability to gain access to assets.
Example: Decoding a weak password (vulnerability) to gain access over the application and potentially misuse it

## Risk
Likelihood of an asset to get exploited because of a vulnerability.
Example: Vulnerability: Weak password for an university database, Asset: Student information, Risk: Student information is exposed and can potentially get misused

## Security Control
The process of reducing the risk by setting up protocols.
Example: Risk: Weak password, Security control: Multi factor Authentication, Strong password policy, Login rate limiting, Account lockout

## Authentication vs Authorization 
Authentication: Verifies the user or a person
Authorization: Determines what the user is allowed to do

## Principle of least privilege
The user should only be given permissions that are required to perform their task
Example: In a college application, the user only needs to read student name, student id and course and so the user shouldn't have permission to drop database, create user or delete students.
